# Chi-La-Sow Ethnic Wear

A premium, responsive ethnic wear e-commerce web application inspired by contemporary luxury fashion layouts.

## Features

- **Hero Banner Slider**: Dynamic full-screen banner slider with auto-rotation, touch/swipe and keyboard navigation, featuring dedicated high-resolution desktop and mobile assets.
- **Product Catalog**: Curated collections of Kurtis, Sarees, and Half-Sarees with dynamic pricing, discount tags, and interactive size/color selections.
- **Interactive Cart & Drawer**: Full client-side shopping cart drawer with live subtotal calculation, quantity adjustment, and item removal.
- **Community Video Reels**: Responsive vertical video showcase highlighting customer stories and real-world styling.
- **Premium Subscription Modal**: Time-delayed (5-second) modal with Indian mobile number (+91) validation and persistent daily dismissal logic synced across tabs via `localStorage`.
- **Responsive Navigation & Footer**: Minimal sticky navigation bar and collapsible multi-column footer optimized for desktop and mobile viewports.

## Tech Stack

- **HTML5** (Semantic markup, `<picture>` responsive media)
- **CSS3** (Custom properties, Flexbox, CSS Grid, mobile-first responsive design)
- **Vanilla JavaScript** (ES6+, DOM manipulation, Storage API)
- **Vercel** (Edge static hosting with security headers)

## Local Development

To run the site locally:

```bash
# Using Python
python3 -m http.server 8000

# Using Node.js
npx serve .
```

Open [http://localhost:8000](http://localhost:8000) in your browser.
